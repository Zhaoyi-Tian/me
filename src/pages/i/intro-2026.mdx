## 笔试题实现（一）：RSI Demo

参考 GEPA，我在 fold harness 上实现提示词的自演化，并通过 OPSD 将提示词回灌进模型权重，随后将提示词重置为空，以此构成一代迭代。实验共迭代 3 代，数据集采用 SWE-bench Lite 的 300 道题目。

这里的 fold harness 是指：agent 拥有一个工具，可以创建继承完整上下文的子 agent。引入这一机制，主要是希望通过该特性让笔试题产生一些有趣的展开。

每一轮迭代流程如下（以第一轮为例）：



主要工作包括：

1. 将 fold 机制对偶地引入反思者，使其能够在有限上下文中对 8 条轨迹进行反思，并提出一条附加至下一轮模型上下文的建议。

2. 根据 SWE-bench grader 的测试报错定位具体函数，并区分是一开始就存在的 test 还是后续注入的隐式 test，再将该信息提供给反思者，以减轻上下文压力。

3. 实现 GEPA 演化的完整流程：

   - 从 train 集中抽取 8 条轨迹并提出一条建议，首先观察该建议在 8 条原始轨迹上能否带来提升；确认提升后，再进入验证集评估。
   - 验证集为每道题维护得分最高的建议；选择下一轮父节点时，则根据各父节点的验证集总分进行概率采样。
   - 为了充分利用 GPU，并行化后可以同时提出 32 条建议，并在验证集上同时验证 4 条建议。

4. 在 verl 上实现 Qwen3.5-9B 的全量 OPSD 微调，并实现前向 KL。

```python title="RSI-Demo：三代演化流程"
W = W0                                      # 初始化模型权重
P0 = ""                                     # 初始提示词为空

for gen in [1, 2, 3]:                       # 共演化三代
    pool = {P0}                             # 初始化本代候选池
    val = {P0: eval(W, P0, D_val)}          # 评估初始提示词
    front = build_front(val)                # 建立逐题最优候选集合

    for rnd in [1, 2, 3, 4]:                # 每代进行四轮搜索
        parent = sample(front)              # 按验证集表现概率采样父节点
        batch = sample(D_train, 8)          # 抽取八道训练题

        trace, old = roll(W, parent, batch)  # 运行父节点并收集轨迹
        advice = reflect(trace)             # 根据轨迹提出一条建议
        child = parent + advice             # 构造新的候选提示词

        _, new = roll(W, child, batch)       # 在同一批题上重新评估

        if sum(new) <= sum(old):             # 没有提升则丢弃
            continue

        val[child] = eval(W, child, D_val)   # 进入完整验证集评估
        pool.add(child)                      # 将候选加入候选池
        front = update(front, child, val)    # 更新逐题最优候选及采样概率

    teacher = best(pool, val)                # 选出本代最佳提示词
    W = opsd(W, P0, teacher)                 # 将提示词能力回灌到模型权重
    P = P0                                   # 重置为空提示词

test(W0, W1, W2, W3, D_test)                # 最后统一进行 held-out 评估
```

### 第一代 held-out 结果

| ----------- | -------------: | -----: | -----: |

| W0 + C1     |             57 | 0.2375 | 0.3333 |

第一代权重回灌后，W1 相较 W0 的 resolved 数增加 15，mean@4 提升 6.25 个百分点，pass@4 提升 8.33 个百分点。后续两代未能延续这一提升，第三代出现明显退化，因此当前结果主要验证了完整流程能够运行，但多代演化的稳定性仍未解决。

问题的难点在于 reflector 的设计，如果给其充足的环境信号并进行合理组织筛选，如何保留其多样性不至于坍塌，如何让其给出足够 focus 的建议不被表面证据误导，都是还需继续探索与迭代的。

## 笔试题实现（二）：AutoResearch Demo

针对我实际遇到的树 attention kernel 速度与显存问题，使用真实数据建立 benchmark，并在其上进行 AutoResearch 演化。

评分以我自己实现的基线为参照，按照以下公式计算：

$$
S=100\sqrt{\frac{T_{\mathrm{ref}}}{T}\frac{M_{\mathrm{ref}}}{M}}.
$$

其中，$T$ 和 $M$ 分别为候选实现的 CUDA 总时间和峰值实际分配显存，$T_{\mathrm{ref}}$ 和 $M_{\mathrm{ref}}$ 为基线的对应指标，因此基线得分为 100。

系统包含三个 AI 角色：Manager 查看此前所有节点的摘要并提出假设；Worker 根据假设修改代码；Summarizer 根据评分结果总结 ExperimentWorker 完成的工作，并在下一轮将总结提供给 Manager。

线性、树状和 Manager 搜索使用相同的根节点、模型、提示词、每轮 15 个节点的预算和评分器，唯一改变的是下一轮的可选父节点：当前最优的 1 个节点、全局最优的 3 个节点或全部可行节点。三种形式各运行 10 次；其中一次 Manager 搜索因控制器误报而中断，因此不纳入统计。

| 形式    | 完整搜索 | 找到可行实现 | 超过 100 分 | 最优分数（均值 / 中位数） |
| ------- | -------: | -----------: | ----------: | ------------------------: |
| 线性    |       10 |           10 |           9 |           131.57 / 133.63 |
| 树状    |       10 |           10 |           7 |           111.97 / 118.93 |
| Manager |        9 |            7 |           6 |            94.63 / 126.85 |

29 次完整搜索中，有 27 次找到可行实现，22 次超过我实现的基线。全局最优候选由线性搜索在第 14 个节点找到，得分为 **152.62**：CUDA 总时间从 **14.981 s** 降至 **12.327 s**（减少 17.7%，等价于加速 1.22×），峰值实际分配显存从 **8.50 GiB** 降至 **4.44 GiB**（减少 47.8%）。其核心是让 FlashAttention 反向传播直接写入最终梯度切片并复用缓冲区，从而避免临时梯度的分配与拷贝。在有限预算下，线性搜索最为稳定，这可能与不同搜索结构形成的树深差异有关。

## 笔试题实现（三）：黎曼猜想

基于 [Anthropic 的 Zeta23 Lean 形式化](https://github.com/anthropics/formal-math/tree/main/zeta23)，并沿用 [ainta/zeta-simple-zeros](https://github.com/ainta/zeta-simple-zeros) 保留谱缺陷、研究连续零点局部结构的路线，我将黎曼 ζ 函数临界线上简单零比例的[端到端 Lean 纪录推进到 67.3%](https://github.com/Zhaoyi-Tian/zeta-simple-zeros-lean)，刷新了目前的形式化证明 SOTA。此前 Zeta23、三点证书和四点证书分别达到 67.25007%、67.27373% 和 67.28470%；但推广到七点时，问题迅速膨胀为六维证书，传统区间穷举需要近百万节点，完整形式化预计消耗约 1000 CPU-hours。

我们发现了隐藏在七点目标中的稀疏数学结构：将 21 个点对压缩为 15 条关键边，并结合 12 段 phase-affine 包络与精确 Farkas 对偶证书，把百万量级搜索压缩到 1,063 个节点、532 个叶子，最终将端到端 Lean 验证时间降至约 1 小时。这一架构不局限于七点，也为进一步冲击八点、九点证书和更高形式化纪录打开了路径。
